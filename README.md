# Онлайн переводчик — Вариант 18

Лабораторная работа по Docker Compose. Приложение переводит текст и сохраняет историю переводов в базу данных.

## Что делает

- Переводит текст между английским, русским и китайским
- Сохраняет каждый перевод в PostgreSQL
- Показывает историю последних 20 переводов
- Есть кнопка, чтобы поменять языки местами
- Результат можно скопировать кликом

## Из чего состоит

Приложение собрано из 4 контейнеров:

- **frontend** — страница на Nginx, открывается на порту 8080
- **backend** — сервер на Node.js/Express, порт 3000
- **db** — PostgreSQL 16, хранит историю переводов
- **web-service** — собственный микросервис на Node.js, порт 5000. Сначала ищет перевод в локальном словаре, если слова нет — обращается к MyMemory API

Как они связаны: фронтенд стучится в бэкенд, бэкенд идёт в web-service за переводом и сохраняет результат в базу.

## Как запустить

Нужен установленный Docker Desktop.

```bash
git clone https://github.com/Dyberezin/translator-app
cd translator-app
docker compose up --build -d
```

Потом открыть в браузере http://localhost:8080

Остановить:

```bash
docker compose down
```

Если нужно удалить и данные базы:

```bash
docker compose down -v
```

## Как пользоваться

1. Открыть http://localhost:8080
2. Ввести текст, выбрать языки
3. Нажать «Перевести»
4. Нажать «Показать историю», чтобы увидеть прошлые переводы

Кнопка ⇄ между языками меняет их местами, а предыдущий перевод переносит в поле ввода. Если кликнуть по блоку с результатом, текст скопируется. Ещё можно нажать Ctrl+Enter в поле ввода, чтобы перевести без клика.

## API бэкенда

- `POST /api/translate` — принимает `{"text":"hello","source":"en","target":"ru"}`, возвращает `{"translatedText":"привет"}`
- `GET /api/history` — возвращает список последних переводов

Пример запроса:

```bash
curl -X POST http://localhost:3000/api/translate \
  -H "Content-Type: application/json" \
  -d '{"text":"hello","source":"en","target":"ru"}'
```


## Что реализовано по заданию

- 4 контейнера: frontend, backend, db, web-service
- frontend, backend и web-service собираются через build, db берётся готовым образом
- переменные окружения для подключения к базе и сервису перевода
- порты 8080 и 3000 проброшены наружу
- depends_on с проверкой healthcheck у базы
- healthcheck для PostgreSQL
- volume pgdata, чтобы данные базы не терялись
- база сама заполняется через init.sql
- web-service по варианту 18 — собственный сервис перевода
- на фронтенде две кнопки, обе работают

## Технологии

Docker Compose, Node.js 18, PostgreSQL 16, Nginx.
